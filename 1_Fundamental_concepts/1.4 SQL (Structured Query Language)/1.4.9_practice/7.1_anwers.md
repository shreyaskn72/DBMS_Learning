## ✅ **SQL Interview Questions and Answers**

---

### 🔹 **1. Third Highest Salary**

**Q:** Find the third highest distinct salary from the employee table.

**A:**

```sql
SELECT DISTINCT salary
FROM employee
ORDER BY salary DESC
LIMIT 1 OFFSET 2;
```

---

### 🔹 **2. N-th Highest Salary**

**Q:** Find the N-th highest distinct salary from the employee table.

**A:**

```sql
SELECT DISTINCT salary
FROM employee
ORDER BY salary DESC
LIMIT 1 OFFSET N-1; -- Replace N with desired rank
```

---

### 🔹 **3. Employees with Top 3 Salaries**

**Q:** Get full employee details for those who have salaries in the top 3 distinct salary values.

**A:**

```sql
SELECT *
FROM employee
WHERE salary IN (
    SELECT DISTINCT salary
    FROM employee
    ORDER BY salary DESC
    LIMIT 3
);
```

---

### 🔹 **4. Department with Highest Average Salary**

**Q:** Find the department(s) with the highest average salary.

**A:**

```sql
SELECT d.name, AVG(e.salary) AS avg_salary
FROM employee e
JOIN department d ON e.department_id = d.id
GROUP BY d.name
ORDER BY avg_salary DESC
LIMIT 1;
```

---

### 🔹 **5. Employees Without a Manager**

**Q:** List all employees who do not have a manager.

**A:**

```sql
SELECT *
FROM employee
WHERE manager_id IS NULL;
```

---

### 🔹 **6. Employees Who Earn More Than Their Manager**

**Q:** Find employees who earn more than their own manager.

**A:**

```sql
SELECT e.*
FROM employee e
JOIN employee m ON e.manager_id = m.id
WHERE e.salary > m.salary;
```

---

### 🔹 **7. Employees With Salary Above Department Average**

**Q:** List employees who earn more than the average salary of their department.

**A:**

```sql
SELECT e.*
FROM employee e
JOIN (
    SELECT department_id, AVG(salary) AS avg_salary
    FROM employee
    GROUP BY department_id
) dept_avg ON e.department_id = dept_avg.department_id
WHERE e.salary > dept_avg.avg_salary;
```

---

### 🔹 **8. Employees Who Have the Same Salary as Someone Else**

**Q:** Find employees who share the same salary with at least one other employee.

**A:**

```sql
SELECT *
FROM employee
WHERE salary IN (
    SELECT salary
    FROM employee
    GROUP BY salary
    HAVING COUNT(*) > 1
);
```

---

### 🔹 **9. Most Recently Joined Employee in Each Department**

**Q:** Find the most recently hired employee in each department.

**A (basic):**

```sql
SELECT *
FROM employee e
WHERE hire_date = (
    SELECT MAX(hire_date)
    FROM employee
    WHERE department_id = e.department_id
);
```

**A (with window function):**

```sql
SELECT id, name, salary, department_id, hire_date
FROM (
    SELECT *, ROW_NUMBER() OVER (PARTITION BY department_id ORDER BY hire_date DESC) AS rn
    FROM employee
) sub
WHERE rn = 1;
```

---

### 🔹 **10. Count of Employees Hired Each Year**

**Q:** Show how many employees were hired each year.

**A:**

```sql
SELECT YEAR(hire_date) AS hire_year, COUNT(*) AS total_hired
FROM employee
GROUP BY YEAR(hire_date)
ORDER BY hire_year;
```

*(Use `EXTRACT(YEAR FROM hire_date)` if `YEAR()` is unsupported.)*
